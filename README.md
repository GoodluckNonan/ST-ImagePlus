# ST-ImagePlus

一个给 SillyTavern／TauriTavern 用的图片工具箱：**贴图、压图、下图**，外加**折叠刷屏的图片与媒体**。
桌面版与 Android 版都适用。

上游酒馆只有「未送出的输入框」能贴图，已送出的消息要补图只能另外按添加附件；图片太大只能自己先压；
想存下聊天里的图片，行动端又没有可用的长按另存；长篇聊天里一串大图会把文字挤得很难读。
这个扩展把这四件事一次处理掉，每一项都可以单独开关。

---

## 先选一件事做

| 想做什么 | 从哪里开始 |
| --- | --- |
| 给**已送出的消息**补一张图 | 按消息的**铅笔图标**进入编辑，在编辑框里粘贴或拖入图片 |
| 图片太大，上传前先压小 | 扩展设置 → 打开**自动压缩**（预设关闭） |
| 把聊天里的图片存下来 | 用新版 TauriTavern 自带的长按存储；旧版需要角标时，到扩展设置打开**检视器下载钮**或**长按下载** |
| 找到某张图出自哪一层 | 画廊里打开大图 → 左下角**跳转**按钮 |
| 不想被一大串图片刷屏 | 扩展设置 → **在每张图片／媒体上方显示折叠条**（预设开启） |

## 安装

1. 打开酒馆的 **Extensions（扩展）** 面板。
2. 点 **Install extension（安装扩展）**。
3. 填入仓库网址：

   ```
   https://github.com/GoodluckNonan/ST-ImagePlus
   ```

4. 出现第三方扩展警告时确认安装。
5. 在扩展清单中找到 **ST-ImagePlus**，确认已启用。
6. **重新载入 App**。

只接受匿名 `http(s)` Git 远端，请贴仓库根网址，不要用 `/tree/main`、`.git` 或 SSH 网址。

手动安装则是把整个资料夹复制到 `<数据根目录>/default-user/extensions/ST-ImagePlus/`
（桌面版的根目录是酒馆安装目录下的 `data/`；Android 版是
`Android/data/com.tauritavern.client/data/`，Android 11 以上要用支持 SAF 的文件管理器才进得去）。
已经装好的旧资料夹不必搬家，酒馆的 Update 会照原路径更新。

## 贴图：给已送出的消息补图

1. 找到要补图的消息，按**铅笔图标**进入编辑。
2. 把图片放进去：
   - **粘贴**：光标放在编辑框内按 `Ctrl+V`（macOS `Cmd+V`）。手机是截图后在编辑框长按选「粘贴」。
   - **拖放**：把图片文件拖进编辑框。拖入时编辑框会出现虚线外框，松手即上传。
3. 图片立刻附加到该消息并存档，消息上直接看得到。按 **✓** 完成编辑。

- **放入即生效**：上传成功就写进消息并存档。所以放完图按 **✕ 取消编辑**，图片仍会留下；
  要移除请用消息图片上的删除按钮。
- 只处理图片，粘贴纯文字完全不拦截；一次多张会逐张上传；单张上限预设 25 MB（可调整或关闭）。
- 未送出的输入框本来就能贴图，这个扩展不动它——只有开启自动压缩时才会顺带压一遍。

## 压缩：上传前自动缩小（预设关闭）

开启后，**超过设定大小**的图片会在上传前压缩，完成时弹一条限时提示报告实际大小。

| 设置项 | 预设 | 说明 |
| --- | --- | --- |
| 启用自动压缩 | 关 | 总开关。关闭时任何图片都原样上传 |
| 压缩后文件大小上限 | 500 KB | **优先满足**。图片不超过这个值就完全不动 |
| 同时限制长边尺寸 | 关 | 只在需要时才缩放，预设不缩 |
| 压缩后长边最大尺寸 | 2000 px | 上面那项打开后才生效 |
| 最低可接受画质 | 0.5 | 压缩下限，避免为了凑体积把图压烂 |

先降画质去贴合体积上限，画质降到底仍然超标才缩小尺寸（最低不低于 320 px）；
怎么压都达不到目标时会采用能压出的最小结果。格式优先 **WebP**（体积小、保留透明通道），
浏览器不支持 WebP 编码时退回 JPEG，再不行用 PNG。

> 压缩是**有损重新编码、不可逆**：原始画质找不回来，EXIF 等拍摄信息也会被清掉。
> 对截图／漫画会掉一点锐度，介意就把体积上限调大。

## 下载：存图与跳到图片所在楼层

**新版 TauriTavern 自己就能存图**（长按图片，或它内置的下载按钮），桌面版／浏览器也有右键另存，
所以扩展里的**下载角标与长按下载预设都是关闭的**——旧版无法存图、或你就是想要那颗角标时，
到扩展设置里打开即可，功能都还在。打开后，图片右下角会出现圆形下载钮（贴在图片自己的边角上，
不会飘到图片外的空白处，按了也不会关掉大图），触控装置上还能长按图片约 0.6 秒下载
（会先弹确认，避免误触）。

**跳到图片所在楼层**预设可用：画廊里拖出来的图片窗口**左下角**有跳转按钮，按下会先问一句
「即将跳转到这张图片所在的楼层」，确认后把聊天卷到那张图所在的消息，并短暂框一下它。
聊天里点开大图时你本来就在那条消息上，所以那里不给这颗按钮。

跳转会找遍**这个角色的所有聊天**，不只是现在开着的那个：

1. 先看**目前开启的聊天**，找到就直接跳，并顺手关掉检视窗口（它会盖住你刚跳到的消息）。
2. 没有就逐一读**这个角色的其他聊天文件**（从最新的开始）。找到后问你要不要切换过去，
   确认后切到那个聊天再跳；切换时画廊与检视窗口会一起关掉。
3. 全部都没有 → 提示「找不到该图片所在的楼层，该对话可能已被删除」，并问你要不要**一并删掉那张图片**。
   这个删除**无法复原**。

搜索跟着**画廊现在在看哪个角色**走，不是跟着聊天里选中的角色。两者不同时，扩展会从图片路径
认出它属于谁，必要时先帮你切换角色卡再打开那个聊天。

> 两个限制：最多只读 **200 个**聊天文件，若因此没找到，只会提醒你「更旧的聊天没有搜索」，
> **不会**提议删除——证据不完整时删文件太危险。当前开的是**群组聊天**时也拿不到要搜哪个角色，
> 同样只提示找不到、不提供删除。

图片存到哪：**Android** 写进系统的「下载」文件夹（系统不允许直接写入时会跳保存对话框让你选位置）；
**iOS** 跳系统分享面板；**桌面版／浏览器**走浏览器原本的下载行为。所有路径都失败时，
扩展会把图片直接交给系统打开（Android 会用系统浏览器开那张图，在那里长按即可另存）并说明原因，
不会按了没反应。

**文生图的图片与影片不需要额外设定**：它们在酒馆里就是普通的媒体项目，
走同一套渲染与同一个检视器，所以跳转与下载自动适用。

## 折叠：收起刷屏的图片与媒体

开启后，对话里的每张图片／每个媒体都会在**自己的最顶端**多一条**折叠条**，按一下就只折叠那一张，
再按一下展开；有几张就有几条，互不影响。**开启之后新送出、中途贴上的图片预设就是折起的**，
不会再被新图刷屏。

- **一键切换**：魔杖菜单里「检视相簿」旁边那一项。全部已折叠时按一下**全部展开**；
  其余情况（全部展开或部分展开）按一下**全部折叠**。
- **状态会被记住**：酒馆重画消息之后折叠条会自己长回来，并维持你先前折的／开的状态。
- **覆盖两种图片**：酒馆自己的媒体（含影片），以及写在消息文字里的图片（包含外部网址的图）。
- 不想要就在扩展设置里关掉，折叠条会全部消失，一切恢复原样。
- **「折叠的图片不随上下文发送」**（预设关）：勾选后被折叠的媒体不会再送进提示词，省下视觉用量。
  它**只影响送出的内容，聊天存档一个字节都不会被改动**，而且只对 Chat Completion（OpenAI 相容）接口有效。

> 一条消息的媒体若显示为**相簿模式**，酒馆一次只渲染当前那一张，所以那条消息只会有一条折叠条；
> 切到**列表模式**（消息上那颗切换按钮）就会每张图各一条。

---

## 为什么这样做

- **压缩预设关闭**：它是有损且不可逆的，会改变你存进酒馆的画质。这种事不该由扩展替你决定。
- **下载钮与长按下载预设关闭**：新版 TauriTavern 已经原生支持存图，重复给按钮只是多一层遮挡。
  两者都留在设置里，让旧版或想要角标的人自己打开。
- **折叠预设开启**：这是唯一会改变对话外观的功能，但方向是「少一点遮挡」而不是「多一层界面」，
  一个开关就能完全关掉。
- **折叠的新图片预设折起，已经存在的维持原样**：否则每开一次酒馆，整个对话都会突然缩起来。
- **删除孤儿图片一定二次确认，搜索不完整时绝口不提**：删掉的图片无法复原。
  宁可少提供一个方便，也不要让你在「其实只是没搜到」的情况下弄丢文件。
- **不注入额外界面**：没有工具条、没有缩图预览、没有自绘按钮外观。唯一的自绘外观是检视器里那颗
  下载钮（那个容器原本什么都没有）。选图本身用酒馆内置的添加附件就够了。
